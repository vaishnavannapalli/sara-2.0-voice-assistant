# SARA 2.0 — Voice Assistant

SARA 2.0 is a Windows voice assistant built with Python.

## Features
- Voice interaction
- Personal memory and recall
- Open and close applications
- Time and date
- Calculations
- General knowledge and education
- Music recognition
- Location-related features

## Requirements
See `requirements.txt` for the Python dependencies, if included.

## Setup
Use the project's documented setup instructions to configure Python and install the required dependencies.

**Note:** Do not upload passwords, API keys, personal data, or your `.venv` folder.
